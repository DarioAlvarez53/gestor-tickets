# Gestor de tickets

App web para gestionar tickets de soporte: crear, ver, editar, cerrar y eliminar tickets, con filtros, buscador y resumen.

## Funcionalidades

- Crear, editar, cerrar/reabrir y eliminar tickets
- Filtrar por estado y por prioridad, y buscar por título
- Ordenar por prioridad y ver resumen (total, abiertos, cerrados)
- Guardado en localStorage, exportar e importar JSON
- Modo oscuro y diseño responsive

## Tecnologías

- HTML, CSS y JavaScript
- Git y GitHub

## Cómo usarlo

1. Abre `index.html` en el navegador.
2. Agrega un ticket con el formulario.
3. Usa los filtros, el buscador o los botones de cada ticket.
